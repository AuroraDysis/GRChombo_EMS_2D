# CTT2 verification evidence

CAS scope: algebraic identity — production physics not certified.

The exact claim is `g L_g(W) g = P^2 S(W)` for `g=P^2 I`, real Cartesian
W and arbitrary real first derivatives, P>0. Here
`S=dW+dW^T-2 tr(dW) I/3` and `dlogP` is an arbitrary real jet. The witness
is all nine component residuals in the rational Laurent field generated by
P, W, dW and dlogP. Multiplying by P^4 is precisely lowering both indices;
P=0 is excluded. `scripts/cas/ctt2_longitudinal.py` expands each polynomial
residual and asserts exact zero. It also closes two independent chain-rule
residuals for W=(r*a,y*b,z*b)/(1+r), r>0, mu real; r=0 and r=-1 are excluded.
Those use deterministic rational cancellation; no general simplifier is used.
No branch crossing occurs. Status: **PROVED** for these eleven identities.

The runtime transfer uses separately implemented C++ cosine transforms,
polynomial jets and flat strain versus Julia nodal basis interpolation,
ForwardDiff W jets and the full metric connection. No random sampling is used:
the deterministic sample files enumerate all points and panel selections.
Five times 146 physical samples pass at Float64, worst 1.291e-14 with a
pre-existing 5e-13 normalized allowance. The 512-bit AD comparisons and 540
stencil comparisons have their own precision/conditioning budgets in README
and JSON receipts. Status: **CORROBORATED** for the sampled runtime transfer;
it is not a proof over all points or of the production physics.

The Float64 nested-AD taper-face discrepancy was resolved by evaluating the
same supplied formulas at 512 bits, preserving the failing Float64 receipt.
The T1 outer composite AMR norm has slow convergence with legacy ghost fill;
T2 point transfer removes that defect. T3 adds panel-face shells: some fine H
orders flatten or become negative around 2e-13, equally with analytic ghosts.
These controls and their qualifications are recorded in README. Neither
finding is hidden
by the exact symbolic result. Source and input digests are in authentication.json.
EMSCTT/2 uses code units M=1 for the hole's mass. Coordinates, phase and W map
arguments are dimensionless in those units; restoring units gives K, Pi and
covariant Cartesian E/B weight L^-1, metric/scalar/lapse/shift weight 1,
H/M/Gauss weight L^-2. The RMS measure is dx dy, normalized by the same mask
area. No family, mass-rescaling or evolution-stability claim is made.
