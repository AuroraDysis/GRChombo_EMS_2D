## Recording implementation and qualification

[The overlay](t21-recorder.patch) adds one recorder member and a read-only capture branch to `EMSBH2DLevel`, using [t21-recorder.hpp](t21-recorder.hpp). It is delivered as an explicit patch so T21 does not silently rewrite the worktree's pre-existing T17 edits. Apply it once to the pinned source snapshot with `patch -p1 --batch --forward -i Tests/EMSNative/t21-recorder.patch`. A context mismatch is a stop, not permission to improvise a new gauge path. The next card may integrate the same recorder into its source change after repeating the identity checks.

`t21_rhs_capture` defaults off. When omitted or false, the old native RHS loop remains the selected branch. When true, the exact currently constructed `my_ccz4_cartoon` kernel is used, with its existing `t7_capture` algebraic seam enabled. That seam stores the actual complete RHS before KO and the native KO operator applied to zero accumulators; it does not invoke the T7 operation recorder or the serial T13 launch recorder. The actual total RHS is also stored. Direction-wise floating-point KO additions need not make `preKO+KO` bit-identical to the total; the residual is checked against 128 epsilon times the local scale and retained. No recorded contribution is substituted back into an evolved field. The pre-KO label means **complete non-KO RHS, including EMS**, not a vacuum-only geometric source. A separate geometric/matter split for the new driver equation is an audit for the next card.

The live recorder never stops evolution, changes a timestep or uses a static profile. It writes the first four RK steps **per selected level**, with actual RK stage, stage time, level start, h, dt, native integer cell and MPI rank. It records both puncture-adjacent cells and a parameterized native neighbourhood. A preprojection census records the actual chi/lapse minimum and floor activations on that recorded neighbourhood. This is not a continuous whole-grid floor-event census. Capture files are rank- and level-separated, written after the threaded kernel loop, and metadata includes the native kernel type as well as the declared gauge label.

[The recording configuration](t21-recording.json) and [parameter overlay](t21-recording-params.txt) specify the rays, radius, field list and first-stage window. All 28 evolved variables are stored, including every A component, K, lapse, both shift and driver components, both evolved Gamma components, chi, phi/Pi, electric and magnetic fields, and cleaning variables. Runtime choices control the field list, selected levels, three ray directions, puncture radius, number of puncture cells and strip width. Coarse cadence is the run's retained `checkpoint_interval=1`, not a compiled cadence constant.

`B1` and `B2` are named, for example, `B1[experimental:integrated_offset_decaying_0p1]`. A future differential-driver run must use its actual gauge and driver-semantic labels. The metadata must agree with the selected gauge manifest and native kernel type. These driver variables cannot be compared across gauge packages as one observable. `Bx`, `By`, `Bz` retain their electromagnetic meaning. Neither the recorder nor replay executable contains a gauge selector: it uses the class selected by the production level.

## Checkpoint replay and thin histories

It preserves the checkpoint's valid state bits, records before/after bit comparisons and reports any nonfinite value. Ghost refill is part of offline sampling and is not described as preservation of the original stored ghost values. Snapshot state columns retain the **unprojected checkpoint fields**; the RHS uses the production trace-removal and positivity projections on its private copy. ## Relational geometry and its limits

For an approximately spherical cartoon state, the physical angular metric gives a useful radius label that does not use the coordinate field oscillation as its sole guide. At a numerical point let r be distance from the numerical puncture centre, n its radial direction and t the orthogonal direction in the cartoon plane. With ht=t^T h t, the recorded angular area-density radius is

\[
\mathcal R_{\rm loc}=r(ht\,h_{ww})^{1/4}/\sqrt\chi.
\]

It equals the sphere's areal radius in spherical symmetry. Outside that limit it is a **local angular area-density proxy**, not a globally integrated sphere area and not a general coordinate invariant. T21 records `(ht-hww)/(ht+hww)`, the radial–tangential cross metric and the three-ray disagreements. It does not average the rays or declare a spherical-symmetry tolerance after looking at data. If those disagreements matter to a comparison, the physical areal/Misner-Sharp interpretation is unqualified and a full numerical surface-area construction is needed.

The current complete native metric RHS supplies the time derivative of this radius label, with both pre-KO and total versions. Its spatial gradient is the current native fourth-order centred derivative of the radius proxy on the ghost-filled numerical metric. The recorded four-metric contraction is

\[
X=\chi h^{ij}\partial_i\mathcal R_{\rm loc}\partial_j\mathcal R_{\rm loc}
 -\frac{(\partial_t\mathcal R_{\rm loc}-\beta^i\partial_i\mathcal R_{\rm loc})^2}{\alpha^2},
\qquad m_{\rm MS,loc}=\tfrac12\mathcal R_{\rm loc}(1-X).
\]

This is the actual ADM inverse-metric contraction of the specified local scalar proxy, using current numerical geometry, not a static solution or a fit to it. The contraction and mass have the usual spherical geometric interpretation only when that symmetry is qualified. The pre-KO/total X difference exposes dependence on the numerical metric rate; it is not removed. Derivative truncation is not bounded by an interpolation spread on a single rung. Profile uncertainty columns describe sampling and Float64 error, not a certificate for native differentiation or spherical regularity.

The positive-radius time derivative and ADM inverse-metric contraction are verified by exact rational witnesses in [t21-geometry-verify.py](t21-geometry-verify.py). [The witness receipt](t21-geometry-witness.json) reports zero symbolic numerators and forty independent 50-digit four-metric inversions with seed 21009, worst scaled discrepancy below 3.1e-49. The excluded zero-lapse, zero-chi, singular-metric and r=0 loci and positive angular-area branch are explicit. Invalid numerical geometry is marked and retained; it is never clipped. The extractor saves phi and X versus the per-ray radius label, together with radius, mass and angular disagreement for each time. It preserves their radius ordering and any non-monotonic or multi-valued relation; it does not force an inversion of the radius label. Numerical horizon locations must come from the run's qualified finder surfaces, never from the original trumpet file. A retained mean finder radius is only a mean marker; it cannot supply distinct angular horizon locations.
